Este es un proyecto escolar realizado para la materia "lenguajes de programacion", el objetivo era
crear un sistema/proyecto enfocado en la resolucion de problemas aplicados a un entorno local.

En mi caso, decidi crear un sistema de monitoreo en tiempo real para la purificadora en la que trabajaba,
¿Porqué? Existia la prblematica de repartidores que robaban y desviaban fondos ademas de que otros salian
de sus rutas para hacer actividades que no deberian en horario laboral(habia casos de repartidores 
que se iban a dormir a casa).

decidi crear un sistema hibrido web/app para el omnitoreo de unidades en tiempo real el cual es el siguiente:
para el monitoreo, gestion y vizualizacion de datos:
  Se desarrollo un sistema hibrido web/app mediante el cual el jefe de las unidades podia monitorear
  en cada momento que quisiera a las unidades que estan laborando, mostrando las ventas, ubicacion 
  y tiempo en reparto en tiempo real.

  contiene las secciones de gestion de ususarios repartidores y de ventanilla, contraseñas y graficas 
  de ventas por fechas e historial de rutas almacenadas en bases de datos.

  Se decidio crear el sistema hibrido dado que para un usuario movil, es facil y accesible usar una APP,
  para el monitoreo en computadora, la opcion mas viable y rapida fue crear un sistema web mediante el
  cual cualquer dispositivo con navegador pudiera acceder sin necesidad de la APP.

Para el monitoreo de repartidores y despachadores:
  se creo una app movil sin posibilidad fja de usar la opcion web, ¿porque? dado las limitaciones
  de los navegadores respecto al GPS y procesos en segundo plano, se decidio que la mejor opcion era
  desarrollar una app movil en la que se podrian gestionar los procesos precisos en segundo plano sin
  limitaciones del sistema.
